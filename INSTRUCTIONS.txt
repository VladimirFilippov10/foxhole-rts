⚡ БЫСТРЫЙ ЗАПУСК (Live Server):
============================================================

   1. Откройте проект в VS Code
   2. Запустите Live Server (правый клик на index.html → 
      "Open with Live Server")
   3. Игра откроется в браузере

📁 СТРУКТУРА ПРОЕКТА:
============================================================

   index.html          - Разметка и стили (без нижнего меню!)
   js/
   ├── constants.js    - Константы, цвета, утилиты
   ├── vehicles.js     - Иерархия классов (разделена по фракциям!)
   ├── map.js          - Данные карты Deadlands
   ├── ai.js           - ИИ с pathfinding через мосты
   ├── renderer.js     - Рендеринг игры
   ├── game.js         - Игровая логика
   └── main.js         - Точка входа, UI, меню завода

🤖 ИИ:
============================================================

   • Использует правильную технику для своей фракции
   • Pathfinding через мосты (не застревает в воде!)
   • Каждые 300 тиков спавнит пехоту
   • Каждые 500 тиков производит технику
   • Захватывает территории

💡 СОВЕТЫ:
============================================================

   • Захватывайте 7 из 10 городов для победы
   • Используйте мосты F6 и J6 для перехода через реку
   • Wardens: Gallagher — мощный, но медленный
   • Colonials: Hatchet — быстрый манёвренный танк
   • Артиллерия бьёт издалека (350!) — ставьте за линией
   • Клик по миникарте — быстрый переход камеры
   • Производство ТОЛЬКО через клик на завод!
   • Здания очень прочные — не бойтесь атак
