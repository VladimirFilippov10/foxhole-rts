🚀 КАК ЗАПУСТИТЬ:
============================================================

   Вариант 1: Live Server (рекомендуется)
   1. Откройте проект в VS Code
   2. Установите расширение "Live Server"
   3. Правый клик на index.html → "Open with Live Server"
   
   Вариант 2: Прямое открытие
   1. Откройте dist/index.html в браузере
   
   Вариант 3: Python сервер
   cd dist
   python -m http.server 8000
   Откройте http://localhost:8000

💡 СОВЕТЫ:
============================================================

   • Захватите 7 из 10 городов для победы
   • Используйте мосты для перехода через реку
   • Техника НЕ проезжает через города!
   • Пехота ходит между домами
   • Производство только через клик на завод
   • ИИ умный - идёт через мосты
   • Здания прочные - не бойтесь атак
   • Клик по миникарте = быстрый переход
   • Наведите на юнит чтобы увидеть радиус атаки
   • Полоска перезарядки под юнитом (жёлтая → зелёная)
   • Артиллерия стреляет каждые 8 секунд (AoE радиус 60)
   • Выберите юнит чтобы увидеть его характеристики
    • Используйте деревья и камни как укрытие
    • Контролируйте мосты - это ключевые точки!
