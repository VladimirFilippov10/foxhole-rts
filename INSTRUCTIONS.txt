============================================================
    WAR OF THE CONTINENT — 2D RTS (в стиле Foxhole)
              ИНСТРУКЦИЯ ПО ЗАПУСКУ
============================================================

📋 ОПИСАНИЕ ИГРЫ:
   2D стратегия в реальном времени с механиками Foxhole.
   Две фракции: Wardens (синие) и Colonials (красные).
   Захватывайте территории, стройте здания, создавайте
   технику и разгромите противника!

============================================================
⚡ БЫСТРЫЙ ЗАПУСК (самый простой способ):
============================================================

   1. Откройте папку dist/
   2. Найдите файл index.html
   3. Дважды кликните по нему — игра откроется в браузере
   4. Выберите фракцию и начните играть!

   Файл dist/index.html полностью автономен (206 KB).
   Весь код встроен в один файл — сервер не нужен!

============================================================
🌐 АЛЬТЕРНАТИВНЫЙ ЗАПУСК (через локальный сервер):
============================================================

   Если хотите запускать через сервер:

   Вариант 1 — Python:
   > cd dist
   > python -m http.server 8000
   Откройте: http://localhost:8000

   Вариант 2 — Node.js (npx):
   > npx serve dist

   Вариант 3 — VS Code:
   Установите расширение "Live Server" и откройте
   dist/index.html через правый клик → "Open with Live Server"

🏗️ МЕХАНИКИ:
============================================================

   РЕСУРСЫ:
   • Supplies (📦) — для содержания армии
   • Components (⚙️) — для техники
   • Materials (🪨) — для строительства

   ЗДАНИЯ:
   • Town Hall (HQ) — главная база
   • Barracks — обучение пехоты
   • Factory — производство техники
   • Refinery — добыча ресурсов
   • Garrison — оборонительное сооружение
   • Artillery Outpost — артиллерийская позиция

   ТЕХНИКА:
   • Infantry — пехота (дешёвая, быстрая)
   • Light Tank — лёгкий танк (манёвренный)
   • Heavy Tank — тяжёлый танк (мощный)
   • Halftrack — бронетранспортёр
   • Artillery — дальнобойная артиллерия
   • Truck — грузовик (логистика)

   ЗАХВАТ ТЕРРИТОРИЙ:
   • Подведите юнитов к точке захвата
   • Дождитесь заполнения прогресс-бара
   • Захватывайте 7 из 9 территорий для победы!
   • Территории дают пассивный доход ресурсов

============================================================
🛡️ ФРАКЦИИ:
============================================================

   WARDENS (Синие):
   • Тяжёлая бронетехника
   • Промышленное превосходство
   • Дальнобойная артиллерия

   COLONIALS (Красные):
   • Быстрые полугусеничники
   • Партизанская тактика
   • Скоростное производство

============================================================
⚙️ ДЛЯ РАЗРАБОТЧИКОВ:
============================================================

   Установка зависимостей:
   > npm install

   Запуск dev-сервера:
   > npm run dev

   Сборка production:
   > npm run build

   Собранный файл: dist/index.html

============================================================
📁 СТРУКТУРА ПРОЕКТА:
============================================================

   src/
   ├── App.tsx        — главный компонент (меню, HUD)
   ├── gameEngine.ts  — игровая логика, ИИ
   ├── renderer.ts    — рендеринг на Canvas
   ├── types.ts       — типы и константы
   ├── audio.ts       — звуковые эффекты
   ├── index.css      — стили (Tailwind)
   └── main.tsx       — точка входа

   dist/
   └── index.html     — готовая игра (один файл!)
