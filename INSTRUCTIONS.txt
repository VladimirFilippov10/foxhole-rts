✅ ВСЕ ВОЗМОЖНОСТИ:

🎮 СИСТЕМА МЕНЮ:
   • Красивое главное меню с кнопкой "Начать игру"
   • Выбор карты (Deadlands доступна, другие скоро)
   • Выбор фракции (Wardens или Colonials)
   • Выбор режима игры (Реализм, Обычный, Быстрый бой)
   • Навигация "Назад" между экранами

🎮 СИСТЕМА РЕЖИМОВ ИГРЫ:
   • 🎯 Реализм - медленный фарм (×0.3), долгая игра
   • ⚖️ Обычный - стандартный темп (×1.0), баланс
   • ⚡ Быстрый бой - ускоренный фарм (×2.5), быстрые матчи

🗺️ КАРТА DEADLANDS:
   • 14 городов для захвата
   • Полностью открытая местность
   • Шахты ресурсов (10 штук)
   • Детализированная природа (300+ деревьев)
   • Расширенная сеть дорог
   • Свободное перемещение техники

⚔️ ФРАКЦИОННАЯ ТЕХНИКА:
   • Wardens: Devitt, Gallagher 30mm, Niska APC, Warden Artillery
   • Colonials: Hatchet, Falchion, Hoplite APC, Colonial Artillery
   • Логистика: Грузовик (БК), Бензовоз (топливо), Инженер (ремонт)

⛽ СИСТЕМА БК И ТОПЛИВА:
   • Вся боевая техника имеет БК и топливо
   • Автоматическое пополнение в базе (радиус 200 единиц вокруг HQ)
   • Пополнение постепенное - топливо быстрее чем БК
   • Грузовик пополняет БК у другой техники (ограниченный запас!)
   • Бензовоз пополняет топливо у другой техники (ограниченный запас!)
   • Инженерная машина ремонтирует повреждённую технику (ограниченный запас!)
   • Полоски БК (оранжевая) и топлива (синяя) под техникой
   • Логистическая техника возвращается на базу для пополнения
   • Информация о БК и топливе отображается в панели выбранного юнита
   • Расход топлива реалистичный - хватает на долгие перемещения

🎯 АРТИЛЛЕРИЯ - МИНИМАЛЬНАЯ ДАЛЬНОСТЬ:
   • Артиллерия НЕ может стрелять в упор!
   • Warden Artillery: минимальная дальность 150, максимальная 500
   • Colonial Artillery: минимальная дальность 120, максимальная 400
   • Если враг слишком близко - артиллерия не будет стрелять
   • Используйте другие юниты для защиты артиллерии в ближнем бою

👥 СИСТЕМА ЛИМИТОВ ЮНИТОВ:
   • Лимиты увеличиваются с каждой захваченной точкой
   • Базовые лимиты: 20 пехоты, 10 техники
   • +3 пехоты и +2 техники за каждую захваченную точку
   • Отображается в HUD (справа вверху)
   • При достижении лимита - нельзя производить больше юнитов этого типа
   • Захватывайте больше точек для увеличения лимитов!

🚛 ЛОГИСТИКА АРТИЛЛЕРИИ:
   • 🚛 Flatbed - общий для обеих фракций грузовик для артиллерии
   • Большая ёмкость (100 снарядов)
   • Пополняет артиллерию в радиусе 60 единиц
   • Возвращается на базу для пополнения снарядов

⏱️ СИСТЕМА ПРОИЗВОДСТВА:
   • Техника производится с задержкой по времени
   • Чем дороже техника, тем дольше производство
   • Пехота: 5 секунд
   • Лёгкие танки: 12-18 секунд
   • Тяжёлые танки: 22-25 секунд
   • Артиллерия: 28-30 секунд
   • Логистика: 10-20 секунд
   • Очередь производства с прогресс-барами
   • Можно заказывать несколько юнитов подряд
   • Прогресс обновляется в реальном времени

🏰 СИСТЕМА УКРЕПЛЕНИЙ:
   • 🏰 Лёгкий бункер (S:30 C:20 M:25) - HP:300, DEF:10, RNG:120
   • 🏯 Средний бункер (S:60 C:40 M:50) - HP:600, DEF:20, RNG:150
   • 🏰 Тяжёлый бункер (S:100 C:70 M:80) - HP:1000, DEF:35, RNG:180
   • Строительство занимает время (10-20 секунд)
   • Визуальное отображение процесса строительства
   • Бункеры атакуют врагов автоматически после завершения
   • Укрепления можно улучшать до 3 уровня
   • Кнопка BUILD для строительства укреплений
   • ИИ тоже строит бункеры (медленнее чем игрок)

🎯 УЛУЧШЕНИЯ ГЕЙМПЛЕЯ:
   • Производство через клик на завод
   • Умный ИИ - оборонительное поведение, менее агрессивный
   • Техника поворачивается в направлении движения
   • Широкие дороги (24px) - техника не застревает
   • Система обхода препятствий - техника не застревает
   • Увеличенные хитбоксы для выбора
   • AoE артиллерия с выбором цели
   • Радиусы атаки и полоски перезарядки
   • Открытая карта - свободное перемещение
   • Победа только при уничтожении базы противника
   • Система укреплений (бункеры) с улучшением
   • Подпись вражеской техники при наведении
   • Система БК и топлива для техники
   • Логистика: грузовики, бензовозы, инженеры
   • Система лимитов юнитов - увеличивается с захватом точек

🚀 КАК ЗАПУСТИТЬ:
============================================================

   Вариант 1: Live Server (рекомендуется)
   1. Откройте проект в VS Code
   2. Установите расширение "Live Server"
   3. Правый клик на index.html → "Open with Live Server"
   
   Вариант 2: Прямое открытие
   1. Откройте dist/index.html в браузере
   
   Вариант 3: Python сервер
   cd dist
   python -m http.server 8000
   Откройте http://localhost:8000

🤖 ИИ ПРОТИВНИКА (СБАЛАНСИРОВАННЫЙ):
============================================================

   ИИ сбалансирован и не доминирует:
   • Собственная система ресурсов (60% от скорости игрока)
   • Тратит ресурсы на производство как игрок
   • Накопление сил перед атакой (порог 12 юнитов)
   • Координированные атаки на базу и захваченные территории
   • Использование артиллерии для дальнего обстрела
   • Артиллерия отступает если враг слишком близко
   • Артиллерия вынуждает игрока атаковать в ответ
   • Оборонительное поведение - защищает свои территории
   • Переключается между режимами атаки и защиты каждые 3000 тиков
   • Патрулирует свои захваченные точки
   • Реагирует на угрозы своим территориям
   • Каждые 900 тиков спавнит пехоту (если хватает ресурсов)
   • Каждые 1500 тиков производит технику (если хватает ресурсов)
   • 20% шанс произвести артиллерию (с сложности 2)
   • Учитывает лимиты юнитов при производстве
   • Медленнее наращивает сложность (каждые 4000 тиков)
