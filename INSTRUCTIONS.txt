✅ ВСЕ ВОЗМОЖНОСТИ:

🎮 СИСТЕМА МЕНЮ:
   • Красивое главное меню с кнопкой "Начать игру"
   • Выбор карты (Deadlands доступна, другие скоро)
   • Выбор фракции (Wardens или Colonials)
   • Выбор режима игры (Реализм, Обычный, Быстрый бой)
   • Навигация "Назад" между экранами

🎮 СИСТЕМА РЕЖИМОВ ИГРЫ:
   • 🎯 Реализм - медленный фарм (×0.3), долгая игра
   • ⚖️ Обычный - стандартный темп (×1.0), баланс
   • ⚡ Быстрый бой - ускоренный фарм (×2.5), быстрые матчи

🗺️ КАРТА DEADLANDS:
   • 14 городов для захвата
   • Полностью открытая местность
   • Шахты ресурсов (10 штук)
   • Детализированная природа (300+ деревьев)
   • Расширенная сеть дорог
   • Свободное перемещение техники

⚔️ ФРАКЦИОННАЯ ТЕХНИКА:
   • Wardens: Devitt, Gallagher 30mm, Niska APC, Warden Artillery
   • Colonials: Hatchet, Falchion, Hoplite APC, Colonial Artillery
   • Логистика: Грузовик (БК), Бензовоз (топливо), Инженер (ремонт)

⛽ СИСТЕМА БК И ТОПЛИВА:
   • Вся боевая техника имеет БК и топливо
   • Автоматическое пополнение в базе (рядом с HQ)
   • Грузовик пополняет БК у другой техники
   • Бензовоз пополняет топливо у другой техники
   • Инженерная машина ремонтирует повреждённую технику
   • Полоски БК (оранжевая) и топлива (синяя) под техникой

🏰 СИСТЕМА УКРЕПЛЕНИЙ:
   • 🏰 Лёгкий бункер (S:30 C:20 M:25) - HP:300, DEF:10
   • 🏯 Средний бункер (S:60 C:40 M:50) - HP:600, DEF:20
   • 🏰 Тяжёлый бункер (S:100 C:70 M:80) - HP:1000, DEF:35
   • Укрепления можно улучшать до 3 уровня
   • Кнопка BUILD для строительства укреплений

🎯 УЛУЧШЕНИЯ ГЕЙМПЛЕЯ:
   • Производство через клик на завод
   • Умный ИИ - атакует разные точки карты
   • Техника поворачивается в направлении движения
   • Широкие дороги (24px) - техника не застревает
   • Увеличенные хитбоксы для выбора
   • AoE артиллерия с выбором цели
   • Радиусы атаки и полоски перезарядки
   • Открытая карта - свободное перемещение
   • Победа только при уничтожении базы противника
   • Система укреплений (бункеры) с улучшением
   • Подпись вражеской техники при наведении
   • Система БК и топлива для техники
   • Логистика: грузовики, бензовозы, инженеры

🚀 КАК ЗАПУСТИТЬ:
============================================================

   Вариант 1: Live Server (рекомендуется)
   1. Откройте проект в VS Code
   2. Установите расширение "Live Server"
   3. Правый клик на index.html → "Open with Live Server"
   
   Вариант 2: Прямое открытие
   1. Откройте dist/index.html в браузере
   
   Вариант 3: Python сервер
   cd dist
   python -m http.server 8000
   Откройте http://localhost:8000

🎮 СОЗДАНИЕ ИГРЫ:
============================================================

   1. Нажмите "Начать игру" в главном меню
   2. Выберите карту:
      • Deadlands (доступна) - открытая местность
      • Howl County (скоро) - реки и мосты
      • Kingscain (скоро) - пустыня
   3. Выберите фракцию (Wardens или Colonials)
   4. Выберите режим игры:
   
   🎯 РЕАЛИЗМ:
   • Фарм ресурсов: ×0.3 (медленный)
   • Начальные ресурсы: 100/50/40
   • Долгая стратегическая игра
   • Каждая единица техники на счету
   • Рекомендуется для опытных игроков
   
   ⚖️ ОБЫЧНЫЙ:
   • Фарм ресурсов: ×1.0 (стандартный)
   • Начальные ресурсы: 200/100/80
   • Сбалансированный темп игры
   • Оптимальный баланс между скоростью и стратегией
   • Рекомендуется для большинства игроков
   
   ⚡ БЫСТРЫЙ БОЙ:
   • Фарм ресурсов: ×2.5 (ускоренный)
   • Начальные ресурсы: 400/200/150
   • Быстрые сражения с большим количеством техники
   • Можно сразу строить армию
   • Рекомендуется для быстрых матчей

💡 СОВЕТЫ ПО РЕЖИМАМ:
============================================================

   🎯 РЕАЛИЗМ:
   • Берегите каждую единицу техники
   • Сначала захватите шахты для бонусных ресурсов
   • Стройте экономику перед армией
   • Артиллерия очень ценна - защищайте её
   • Игра может длиться 30+ минут
   
   ⚖️ ОБЫЧНЫЙ:
   • Баланс между экономикой и армией
   • Захватывайте города и шахты одновременно
   • Используйте комбинации техники
   • Контролируйте мосты
   • Оптимальная длительность: 15-20 минут
   
   ⚡ БЫСТРЫЙ БОЙ:
   • Сразу стройте армию
   • Агрессивная тактика - захватывайте города
   • Много артиллерии для AoE урона
   • Быстрые решения важнее планирования
   • Длительность: 5-10 минут

============================================================
💡 ОБЩИЕ СОВЕТЫ:
============================================================

   • УНИЧТОЖИТЕ базу противника (HQ) для победы!
   • Захватывайте города и шахты для ресурсов
   • Техника НЕ проезжает через города!
   • Пехота ходит между домами
   • Производство только через клик на завод
   • ИИ умный - атакует разные точки карты
   • Здания прочные - не бойтесь атак
   • Клик по миникарте = быстрый переход
   • Наведите на юнит чтобы увидеть радиус атаки
   • Полоска перезарядки под юнитом (жёлтая → зелёная)
   • Артиллерия стреляет по площади (AoE)
   • Выберите юнит чтобы увидеть его характеристики
   • Используйте деревья и камни как укрытие
   • Стройте бункеры для защиты базы (кнопка BUILD)
   • Используйте грузовики для пополнения БК
   • Бензовозы обеспечивают топливо
   • Инженеры ремонтируют повреждённую технику
   • Наведите на вражескую технику - увидите её название
   • Следите за полосками БК (оранжевая) и топлива (синяя)
   • Техника поворачивается в направлении движения
   • Карта открытая - техника свободно перемещается
